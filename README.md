# Student Grade Calculator

## What it does
A student grade calculator written in C language.
Enter your marks for each subject and it will calculate
your total, average, percentage and final grade automatically.

## Grades
- 90% and above = A+ Excellent
- 80% and above = A Very Good
- 70% and above = B Good
- 60% and above = C Average
- 50% and above = D Below Average
- Below 50% = F Failed

## How to run it
1. Make sure GCC compiler is installed
2. Open terminal and compile:

gcc grade_calculator.c -o grade_calculator

3. Run the program:

./grade_calculator

4. Enter number of subjects and marks when asked
